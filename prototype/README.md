# Stratink Clickable Prototype

This is a front-end clickable prototype for Stratink.

## Included
- Resident login
- Resident dashboard
- Maintenance requests
- Documents and bylaws
- Visitor parking
- Amenity booking
- Move in / move out
- Package tracking
- Community marketplace
- Admin dashboard
- Admin modules

## How to use locally
Open `index.html` in a web browser.

## How to publish on GitHub Pages
1. Upload all files to a GitHub repository.
2. Go to Settings > Pages.
3. Choose the main branch and root folder.
4. Save.
5. GitHub will provide a public prototype link.
